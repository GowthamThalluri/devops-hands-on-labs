# Git Practice

## Day 1

Today I practiced creating a Git repository and connecting it to GitHub.

### Commands Practiced

- git init
- git status
- git add
- git commit
- git log
- git remote
- git push
- git pull

### What I Learned

Git does not track empty directories.

Untracked files are new files that Git is not tracking yet.

`git add` moves changes into the staging area.

`git commit` saves staged changes in the local repository.

`git push` sends local commits to GitHub.

`git pull` retrieves and integrates changes from the remote repository.
