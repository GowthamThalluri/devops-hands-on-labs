# Linux Hands-On Practice

This section documents my Linux fundamentals and hands-on practice as part of my DevOps learning journey.

My focus is on understanding commonly used Linux commands, practising them in Ubuntu on WSL, and applying them to practical troubleshooting scenarios.

## Topics Practised

### 1. Filesystem Structure and Navigation
- Understanding common Linux directories such as `/`, `/home`, `/etc`, `/var`, `/tmp`, `/usr`, and `/opt`
- Navigating directories using `cd` and `pwd`
- Understanding absolute and relative paths
- Inspecting files and directories using `ls`

### 2. File Searching
- Finding files and directories using `find`
- Searching by filename and file type
- Using wildcard patterns
- Finding empty and large files
- Searching by modification time
- Limiting search depth

### 3. File and Directory Management
- Creating files using `touch`
- Creating directories using `mkdir`
- Copying files and directories using `cp`
- Moving and renaming files using `mv`
- Removing files using `rm`
- Removing empty directories using `rmdir`
- Practising recursive copying and deletion with caution

### 4. Permissions and Ownership
- Understanding read, write, and execute permissions
- Inspecting file permissions and ownership
- Practising basic permission changes using `chmod`
- Checking user and group membership using `id`
- Understanding setgid and `umask`

### 5. Disk Usage and Mounted Filesystems
- Checking filesystem capacity using `df`
- Inspecting directory sizes using `du`
- Identifying mounted filesystems using `findmnt`
- Understanding filesystem types and mount points

## Tools and Environment

- Ubuntu on Windows Subsystem for Linux (WSL)
- Linux command line
- Visual Studio Code
- Git and GitHub for documenting practice

## Learning Approach

Each topic is practised through hands-on tasks and troubleshooting scenarios. Commands are tested in a practice environment, and their outputs are inspected to understand their behaviour.

**Current focus:** Building strong Linux fundamentals before moving to more advanced administration and automation topics.

Some topics are still being practised. This repository will be updated as new concepts are completed and verified.
